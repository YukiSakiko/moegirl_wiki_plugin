# 萌娘百科插件

装上这个插件后，麦麦就多了一个"去萌娘百科查一下"的能力。

当你们聊到某个角色、作品、设定或梗，而她的知识不够用或不确定时，她会自己去萌娘百科查词条，再用查到的内容来回答你——通常会带上词条链接，方便你自己点进去看。

## 装好之后是什么样的

你在群里或私聊里问：

> 帮我查查萌娘百科的词条「初音未来」，她是谁呀？

麦麦可能会回你（以下依据萌百词条真实摘要）：

> 初音未来，Crypton做的声音库软件和拟人化形象，能拿去喂VOCALOID唱歌的那种
> 中文一般直接叫初音，日英简称Miku，是角色主唱系列第一作，编号CV01
> 跟镜音铃·连、巡音流歌、MEIKO、KAITO一起叫Piapro角色，词条链接发你了

不需要任何命令，正常说话即可。提到"萌娘百科""萌百"更容易触发查询，但平时聊到 ACGN 相关话题她也能自己判断要不要查。

## 安装

### 方式一：插件中心（推荐）

在 MaiBot WebUI 的「插件市场」中搜索本插件并安装，依赖会自动处理。

### 方式二：手动克隆

把仓库克隆到 MaiBot 的 `plugins/` 目录下：

```bash
cd /path/to/MaiBot/plugins
git clone https://github.com/ValleyWinds/Moegirl-Wiki.git valleywinds.moegirl-wiki
```

放好后 1~2 秒内会被自动加载，**不需要重启 MaiBot**。之后在 WebUI「插件扩展」页确认它的状态是"加载成功"即可。

## 配置

插件开箱即用，默认配置适合绝大多数场景，一般什么都不用改。

想微调的话，在 WebUI 的「插件扩展 → 萌娘百科插件 → 设置」里可以直接改（改完点保存即可生效）：

| 配置项 | 说明 |
| --- | --- |
| 请求超时（秒） | 查询萌娘百科接口时的等待上限，网络较差可适当调大 |
| 登录 Cookie | 高级选项，留空即可。当前查询流程不依赖 Cookie |
| 优先使用高级搜索 | 默认开启，查询效果更好，失败时自动切换备用方式 |
| 缓存生存时间（秒） | 相同查询在这段时间内不会重复请求萌百，设为 0 关闭缓存 |
| 候选词条上限 | 词条名有歧义时，最多给麦麦列多少个候选 |
| 优先精确标题匹配 | 开启后只有找到非常确定的主词条才返回详细介绍，否则列出候选让麦麦自己判断 |

## 常见问题

**问：她会查错 / 不查怎么办？**
问法里带上"萌娘百科"或"萌百"基本都会触发。如果词条名有歧义，她会先拿到候选列表再挑。

**问：为什么有时候回答变慢了？**
查询萌百需要一次网络往返，比纯聊天多花几秒，属于正常现象。同一个词短时间内重复问会走缓存，不会反复请求。

**问：对萌娘百科会不会造成压力？**
不会。所有查询都有缓存和数量上限，走的是官方公开的 API 接口。

**问：装完之后原来的人设、聊天风格会变吗？**
不会。这个插件只是给麦麦加了一个"查资料"的工具，用不用、怎么说话都由她自己决定。
