# 萌娘百科知识补全插件

为 MaiBot / 麦麦增加查询萌娘百科的能力，方便在聊天时查阅角色、作品、设定和梗等资料，并提供词条链接供你进一步阅读。

## 功能

- 查询词条摘要、介绍和原文链接。
- 找到匹配明确的主词条时，附带相关词条，补充聊天语境。
- 关键词有歧义时，提供候选词条供进一步确认。
- 支持缓存、请求超时和候选数量设置，可在 WebUI 中调整。

## 怎么使用

安装后，在群聊或私聊里正常提问即可，不需要专门的查询命令，例如：

> 帮我查查萌娘百科，初音未来是谁？

> 查一下萌娘百科里东方 Project 的介绍。

> 这个梗是什么意思？能去萌百查一下吗？

麦麦可以根据查询结果组织回答，并附上词条链接。是否发起查询、如何回复，取决于当前模型的工具调用能力、人设和聊天上下文；明确提出查询要求有助于表达你的意图，但不保证每次都会调用。

## 安装

### 通过插件市场安装

在 MaiBot WebUI 的「插件市场」中搜索「萌娘百科」并安装。若市场中暂未提供本插件，可以使用下面的手动安装方式。

### 手动安装

将本仓库克隆到 MaiBot 的 `plugins/` 目录：

```bash
cd /path/to/MaiBot/plugins
git clone https://github.com/YukiSakiko/moegirl_wiki_plugin.git moegirl_wiki_plugin
```

支持热加载的 MaiBot 版本通常会自动发现新插件。安装后，请在 WebUI 的「插件扩展」中确认插件已成功加载并启用；未自动加载时，可按当前 MaiBot 版本的说明重新加载或重启。

如果加载失败，请查看页面或日志中的错误提示，确认宿主版本、依赖和网络环境是否满足要求。

## 配置

一般可以先使用默认配置，无需填写登录 Cookie。需要调整时，在 WebUI 的「插件扩展 → 萌娘百科插件 → 设置」中修改并保存，后续查询会使用新配置。

| 配置项 | 说明 |
| --- | --- |
| 请求超时（秒） | 默认 10 秒，限制单次网络请求的等待时间，网络较差时可适当调大。 |
| 登录 Cookie | 可选，当前查询流程不依赖 Cookie，通常留空即可。 |
| 优先使用高级搜索 | 默认开启，优先尝试高级搜索，不可用时尝试备用搜索方式。 |
| 缓存生存时间（秒） | 默认 300 秒，命中缓存时复用已有结果；设为 0 关闭缓存。 |
| 候选词条上限 | 默认 5，控制返回的候选词条数量。 |
| 优先精确标题匹配 | 默认开启，匹配明确时返回主词条介绍，否则列出候选；关闭后返回候选列表。 |

登录 Cookie 属于个人凭据，请勿将其提交到公开仓库或分享给其他人。

## 常见问题

### 为什么没有查询，或者查到的不是我想要的词条？

先确认插件已成功加载并启用，当前模型支持工具调用。可以明确提出「查询萌娘百科」，或补充完整的角色名、作品名和上下文。词条名有歧义时，麦麦可能会先拿到候选结果，仍需进一步确认。

### 为什么查询比普通聊天慢？

一次查询可能包含搜索、词条详情和相关词条补查等多次网络请求，耗时受网络状况和站点响应影响。命中缓存时可以复用结果；重启、重新加载插件或修改配置后，缓存会重新积累。

### 会不会给萌娘百科造成访问压力？

插件通过缓存和查询数量限制减少重复请求，但不代表完全没有访问负载。请避免高频、批量查询，尤其是在关闭缓存或多人同时使用时。

### 会改变麦麦的人设和聊天风格吗？

插件本身不修改人设配置，只提供查资料的能力。最终回答的措辞和内容仍由模型、人设以及当前聊天上下文决定。
